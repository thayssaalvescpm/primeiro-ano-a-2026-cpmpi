# 🎮 Jogos Digitais — 1º Ano A | CPM-PI

> **Projetos desenvolvidos por estudantes do 1º ano do CPM-PI durante o ano letivo de 2026.**

## 📖 Sobre o Projeto

Este repositório reúne jogos digitais desenvolvidos pelos alunos do **1º ano A do CPM-PI**, como parte das atividades de aprendizagem relacionadas à programação e ao desenvolvimento de jogos digitais.

Os projetos foram desenvolvidos utilizando a linguagem **Python 3.11.9**, a biblioteca **Pygame** e o ambiente de desenvolvimento **Thonny**, com o auxílio de ferramentas de **Inteligência Artificial Generativa**.

A proposta busca aproximar os estudantes do universo da programação por meio da criação de jogos, incentivando a experimentação, a criatividade e a aplicação prática dos conhecimentos adquiridos em sala de aula.

Cada projeto apresenta ideias, mecânicas e desafios próprios, refletindo o processo de aprendizagem dos estudantes e suas diferentes formas de explorar o desenvolvimento de jogos.

## 🎯 Objetivos do Projeto

O desenvolvimento dos jogos tem como principais objetivos:

- Introduzir conceitos fundamentais de programação por meio de atividades práticas.
- Estimular o raciocínio lógico e o pensamento computacional.
- Desenvolver a criatividade e a capacidade de resolver problemas.
- Explorar a criação de jogos digitais utilizando Python e Pygame.
- Compreender a relação entre código, regras, interações e elementos visuais de um jogo.
- Incentivar a autonomia, a experimentação e a aprendizagem contínua.
- Promover o uso consciente da Inteligência Artificial Generativa como ferramenta de apoio ao desenvolvimento.
- Valorizar as produções dos estudantes e compartilhar seus resultados.

## 🛠️ Tecnologias e Ferramentas

### Python 3.11.9

Linguagem de programação utilizada para implementar a lógica dos jogos, definir regras, processar informações e controlar as interações.

### Pygame

Biblioteca utilizada para o desenvolvimento de jogos com Python. Permite trabalhar com janelas gráficas, imagens, sons, eventos, teclado e outros recursos interativos.

### Thonny

Ambiente de desenvolvimento integrado (IDE) utilizado pelos estudantes para escrever, executar, testar e depurar os códigos Python.

### Inteligência Artificial Generativa

Ferramenta de apoio ao processo de desenvolvimento, podendo auxiliar na compreensão de conceitos, na elaboração de soluções, na identificação de erros e na experimentação de ideias.

O uso dessas ferramentas deve estar associado à compreensão do código, à avaliação crítica das sugestões e à participação ativa dos estudantes no processo de aprendizagem.

## 📚 Conceitos de Programação Explorados

Os projetos permitem trabalhar diferentes conceitos fundamentais da programação, conforme as funcionalidades implementadas em cada jogo.

- **Variáveis e tipos de dados:** armazenamento e manipulação de informações.
- **Operadores:** realização de operações matemáticas, comparações e expressões lógicas.
- **Estruturas condicionais:** criação de decisões e regras para o funcionamento dos jogos.
- **Estruturas de repetição:** execução contínua de instruções e controle dos ciclos de jogo.
- **Entrada e saída de dados:** interação entre o programa e o jogador.
- **Eventos:** identificação de ações realizadas pelo usuário, como pressionar teclas.
- **Funções:** organização e reutilização de partes do código, quando utilizadas.
- **Lógica de jogo:** implementação de objetivos, regras, pontuação e condições de vitória ou derrota.
- **Elementos gráficos:** criação de interfaces e representação visual dos elementos do jogo.

## 💻 Requisitos para Execução

Para executar os projetos, recomenda-se utilizar:

- Computador com sistema operacional compatível com Python e Pygame.
- Python **3.11.9**.
- Thonny configurado para utilizar o Python 3.11.9.
- Biblioteca Pygame instalada no ambiente Python selecionado.
- Arquivos `.py` disponíveis neste repositório.

> **Importante:** a necessidade de arquivos adicionais, como imagens, fontes ou sons, depende de cada projeto. Caso algum jogo utilize esses recursos, eles também deverão estar disponíveis nos caminhos esperados pelo código.

## 🚀 Como Executar os Jogos

### 1. Instale o Thonny

Instale o ambiente de desenvolvimento Thonny, caso ainda não esteja disponível no computador.

### 2. Configure o Python

Verifique se o interpretador selecionado utiliza o Python 3.11.9.

### 3. Instale o Pygame

No Thonny:

1. Abra o menu **Ferramentas**.
2. Selecione **Gerenciar pacotes**.
3. Pesquise por `pygame`.
4. Selecione o pacote e realize a instalação.

A instalação deve ocorrer no mesmo ambiente Python utilizado para executar os jogos.

### 4. Abra o projeto

1. Abra o Thonny.
2. Acesse **Arquivo → Abrir**.
3. Navegue até a pasta do repositório.
4. Selecione o arquivo `.py` correspondente ao jogo desejado.

### 5. Execute o jogo

Clique no botão **Executar** ou pressione `F5`.

A janela do jogo será aberta, caso o programa esteja configurado para iniciar sua interface gráfica.

### 6. Explore os projetos

Experimente os diferentes jogos, observe seus códigos e identifique como os conceitos de programação foram utilizados em cada implementação.
